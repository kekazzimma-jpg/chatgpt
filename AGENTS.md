# AGENTS.md

Regole minime per qualunque agente (Claude, Codex, altri) che lavora su questo repo.

1. **Prima di tutto, leggi `STATO.md`.** È la memoria viva del progetto. Contiene scopo, struttura reale, problemi aperti e prossimo passo consigliato.
2. **Non inventare dettagli.** Basati solo su ciò che è scritto nei file reali del repo. Se una cosa non è certa, scrivi "da verificare" invece di supporre.
3. **Aggiorna `STATO.md` a fine sessione.** Almeno: il diario sintetico della sessione, i problemi risolti/aperti, il nuovo "prossimo passo consigliato".
4. **Lavora per piccoli batch.** Una modifica tematica alla volta. Niente refactor trasversali non richiesti.
5. Non creare altri file di documentazione oltre a `AGENTS.md`, `CLAUDE.md`, `STATO.md` senza richiesta esplicita.
